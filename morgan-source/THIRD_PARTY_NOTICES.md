# 第三方与来源

项目最初基于 NousResearch/hermes-agent 探索小模型 Agent，随后将聊天产品单独实现并迭代。此目录只包含当前聊天入口所需模块，没有打包完整 Hermes 或 vendor_core。保留现有源文件中的来源注释。

原工作目录记录的上游版本为 7b9cb2e39c9bc5d46c96dfb9425b0933cbe6603a。上游 MIT 许可原文存于 docs/licenses/hermes-agent-MIT.txt，仅说明上游许可，不表示本项目自有代码已选择同一许可证。

pywebview、WebView2、DDGS、llama.cpp、模型与 Python 各有独立许可。依赖清单不包含这些软件的安装载荷；获取和使用时保留各自声明。当前未给本项目自有代码新增开源许可。
