# 本地数据与联网

- 聊天记录、偏好记忆及相关元数据存入本地 SQLite；当前存储没有提供数据库加密。
- 人格正文与开关是本机配置。本源码包使用空白人格示例，没有复制用户人格或个人偏好。
- 模型配置中的文件路径、运行状态、日志及请求记录也属于本机数据，不上传源码仓库。
- 开启网页搜索后，查询会发送给外部搜索服务；查询构造可能引用少量相关上文以补齐对象。需要完全离线时关闭搜索。
- 记忆提取和摘要依赖本地模型能力，可能出现遗漏或错误；可以通过页面检查、修改或删除。
- `.gitignore` 可防止常见运行文件被误加入，但不是加密、备份或访问控制，也不能撤回已经提交的敏感信息。

源码整理只读取生产数据库的原始字节哈希，没有通过 SQLite 打开生产库，也没有迁移用户聊天。
